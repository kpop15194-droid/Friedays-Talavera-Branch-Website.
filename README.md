# Friedays Talavera Website

A responsive food menu and online order preparation website for Friedays Talavera.

## Features

- Responsive design for desktop and mobile
- Complete Friedays food and drinks menu
- Menu categories and filters
- Flavor selection for selected chicken products
- Add-to-cart functionality
- Quantity controls
- Automatic total calculation
- Customer order form
- Copyable order message
- Facebook page link

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Project Files

- `index.html` - Website structure
- `styles.css` - Website design and layout
- `app.js` - Menu, cart, and order functions
- `README.md` - Project documentation

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.

## Publishing with GitHub Pages

1. Open your GitHub repository.
2. Go to Settings.
3. Select Pages.
4. Under Build and deployment, select Deploy from a branch.
5. Choose the `main` branch.
6. Select `/ (root)` as the folder.
7. Click Save.
8. Wait for GitHub Pages to publish your website.

## Important Notes

- Prices are based on the menu provided by the store and should be confirmed by the owner before public launch.
- The order form generates a message for the customer to copy and send.
- Orders are not automatically transmitted to the store.
- Delivery, pickup, payment methods, promotions, and operating hours must be confirmed by the owner.
- The Facebook link should be checked to ensure it points to the correct official page.
